쉬운가계부 기능 안내

어려운 말 없이, 일상에서 바로 쓰는 기능을 화면과 함께 모았어요.

입력

수입/지출을 고르고 카테고리를 누르면 금액 키패드가 바로 열립니다. 결제수단·메모도 한 흐름에서 남길 수 있어요.

  • 어제·오늘 버튼으로 날짜를 빠르게 변경
  • 자주 쓰는 금액 칩과 00·000 키
  • 저장 후 키보드가 함께 닫혀 다음 입력이 편함
  • 달력에서 들어온 경우, 저장 후 그 날짜로 복귀

달력

월 달력에서 날짜별 수입·지출 흐름을 보고, 날짜를 누르면 그날 내역을 확인합니다. + 버튼으로 그 날짜에 바로 기록할 수 있어요.

  • 날짜별 합계와 상세 목록
  • FAB(+)로 선택 날짜 입력
  • 저장 후 같은 날짜 달력으로 되돌아오기
  • 위젯 ‘달력’으로 오늘 날짜 바로 열기

내역 · 검색

목록을 스크롤해도 이번 달 수입·지출·차액이 상단에 고정됩니다. 전체/수입/지출 토글과 다양한 조건으로 기록을 모아 볼 수 있어요.

  • 카테고리 · 메모 · 금액 · 기간 · 결제수단 검색
  • 자주 쓰는 검색 조건을 이름으로 저장
  • 매달 같은 필터를 한 번에 불러오기
  • 차액 = 총수입 − 총지출 (통장 잔액 아님)

통계

기간을 선택하면 수입·지출·차액과 카테고리 비중을 보여 줍니다. 한 달 결산이나 “식비 비중”을 확인할 때 유용해요.

  • 기간별 합계 요약
  • 카테고리 비중으로 소비 패턴 점검
  • 내역·달력과 이어지는 결산 흐름

위젯 · 알림 · 백업

홈 위젯으로 오늘 수입·지출과 최근 내역을 보고, ‘입력’·‘달력’으로 바로 이어집니다. 미기록·고정비 알림과 파일 백업으로 놓치지 않게 도와줘요.

  • 위젯 크기 조절 (합계만 / 목록 포함)
  • 오늘 미기록 · 고정비 예정 알림(선택)
  • 설정에서 백업 파일 저장·복원

카테고리 · 고정비

화면은 설정 안에 있지만, 매일 쓰는 기록의 기반이 되는 기능이에요.

카테고리

아이콘, 자주 쓰는 금액, 숨김을 관리할 수 있어요. 처음 실행에서 고른 뒤에도 설정에서 언제든 추가·정리할 수 있습니다.

고정비 규칙

급여·월세·구독처럼 반복되는 항목은 규칙만 등록하면 해당 날짜에 자동 반영됩니다. 규칙을 멈춰도 이미 생성된 기록은 그대로 남아요.
